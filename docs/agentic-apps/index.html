Agentic Apps¶

Agentic Apps are AI-native enterprise applications built in Oracle AI Agent Studio. In an Agentic App, a team of specialized AI agents does the reasoning, fetches the data and composes the user interface. The app does more than show records. It analyzes the business state, decides what matters, recommends what to do, and helps the user carry it out without leaving the page.

In one sentence

A traditional app retrieves data and presents it. An Agentic App works out what the data means and brings only the decisions that need a human to the user.

Why Agentic Apps?¶

Enterprise software has moved through three generations:

Era Purpose Behavior Measured by
Systems of record Document the business Static rules, record transactions, retrieve history Task completion
Single source of truth Transact for the business Unified data, policies, roles and processes (e.g., Fusion Applications), but waits for the user Process efficiency
Systems of outcomes Run the business Pursues objectives, decides in real time, reasons and adapts Business outcomes

Agentic Apps belong to the third era. Instead of asking a manager to run an attrition report, filter it and decide who needs attention, the app opens with the answer: which employees are at risk, why, and what to do next.

Traditional apps vs. Agentic Apps¶

Dimension Traditional app Agentic App
Data handling Fetches and displays raw data Analyzes, prioritizes and recommends
UI composition Hard-coded screens and flows Displays generated at runtime by agents from standard widgets
User interaction User navigates to find information Information is brought to the user
Architecture Monolith or microservices Composable teams of specialized agents
Change model Code changes Prompt and visual configuration
Value Efficient data access A partner in making decisions

The four areas¶

Every capability of an Agentic App maps to one of four pillars:

flowchart LR
    A[Information Displays<br/><small>see what matters</small>] --> B[Actionable Insights<br/><small>decide and execute</small>]
    B --> C[Communications<br/><small>follow through</small>]
    D[Ask Oracle Advisors<br/><small>explore and ask</small>] --- A
    D --- B
Pillar What it does Learn more
Information Displays Agent-generated charts, cards, lists, tables, forms and Sankey diagrams Widgets
Actionable Insights Recommended next steps the user can run from the app Actions
Communications Pre-drafted emails, messages, PDFs and PowerPoint decks Communications
Ask Oracle Advisors Natural-language questions answered by the relevant specialist agents Ask Oracle

How you build them¶

AI Agent Studio offers two paths that share one Fusion-native framework and runtime:

A visual builder inside AI Agent Studio. Describe the business objective in plain language; the builder suggests a structure and recommends agents. Then refine the layout, prompts, actions, communications and templates visually, preview the app and publish it.

Introduced in Release 26B. See Using the Builder UI.

A skill/CLI that gives AI coding assistants (for example Claude Code or OpenAI Codex, working in VS Code or a terminal) the Fusion-specific knowledge and commands needed to generate, validate, test and deploy Agentic App artifacts, with Git-based lifecycle and CI/CD.

Available in Release 26C. See Pro-Code (AI Studio Skill).

Either way, the finished app runs inside Fusion Applications. It works on live transactional data and business objects, and it inherits Fusion role-based security, approvals and auditability. There is no separate runtime to host or secure.

  • Autonomous Outcomes: goals, application skills, workflow capabilities, and example tasks.
  • Ask Oracle starter queries: dynamic suggestions and record lookups.
  • Ask Oracle value filters: dynamic suggestions and record lookups.
  • Template Builder: format-specific controls, including podcast templates where supported.
  • App Context: default context, context search, and scope switching.
  • ATLAS testing: workflow regression coverage and app panel validation.
