Template Builder¶

Templates define reusable content for communications and artifact generation. App-local templates live in appConfig.templates. Create a template before linking a communication to it; the selected template determines the output format and structure.

Choose a template type¶

Type Structure Key controls
PowerPoint (ppt) Ordered slides Slide content, generated or fixed titles, presentation type; upload .pptx or .potx for structure extraction
PDF (pdf) Document title and ordered sections Generated or fixed title; section autofill; presentation guidance
Email (email) Recipients, subject, and body sections Generated or fixed recipients/CC and subject; static or generated body content
Text (text) Ordered text sections Section autofill and optional presentation guidance
Podcast (podcast) Hosts and spoken sections Host names and voices; per-section host selection, data instructions, and voice instructions

Common editor controls¶

Set Template Name to identify the reusable template, then build its slides or sections in the order the output should follow. A template name identifies the definition; use the type-specific title controls for titles in the generated output.

For section-based templates, Section Title labels a section in the builder. Content instructions specify what to generate, while presentation instructions specify how it should read or be formatted. For example, request delivery metrics and supporting evidence in the content instructions, and a concise paragraph followed by a table in the presentation instructions.

PowerPoint¶

Add slides or upload an existing .pptx/.potx template. Use Slide Content for what the slide should contain and Presentation Type for its layout.

Control Behavior
Auto Generate Title Off reveals Slide Title for a fixed title; on hides that field and generates the title
Slide Content Instructions for the information to include on the slide
Presentation Type → Paragraph or Bullets Selects the output style without an additional instructions field
Presentation Type → Chart Reveals Chart Instructions for chart-specific guidance
Presentation Type → Custom Reveals Custom Instructions for layout or formatting guidance

After upload processing, the editor displays the uploaded filename until the file is removed. PowerPoint templates start without slides; add the structure you need.

PDF¶

Use PDF templates for a document with a title and ordered sections. The editor provides Template Name, Auto Generate Title, a section list, Section Title, Auto Fill Section, and Configure Presentation.

Control Behavior
Auto Generate Title Off reveals the fixed document Title; on hides it and generates the title
Auto Fill Section On reveals Section Content for generation instructions; off hides it
Configure Presentation On reveals Presentation Instructions for tone, phrasing, or formatting; off hides it

Create a section for each coherent topic, such as an executive summary, evidence, and next steps.

Text¶

Text templates contain ordered sections. Set Section Title to identify each section and use these controls to guide generation:

  • Turn Auto Fill Section on to reveal Section Content; turn it off to hide those instructions.
  • Turn Configure Presentation on to reveal Presentation Instructions for phrasing or structure; turn it off to hide that field.

Keep the content instructions focused on the information to include and presentation instructions focused on how to express it.

Email¶

Email templates combine recipient settings, a subject, and ordered body sections.

Control Behavior
Auto Generate Recipients Off reveals fixed Recipient and CC fields; on hides them and generates the values
Auto Generate Subject Off reveals a fixed Subject field; on hides it and generates the subject
Static Content Section On reveals the Static Content editor and hides generated-content controls for that section
Generated section With Static Content Section off, use Auto Fill Section and Section Content for generation
Configure Presentation Available for generated sections; on reveals Presentation Instructions for wording or formatting

Use static sections for exact wording, such as an approved footer. Use generated sections for content that varies with the request or business context. Presentation instructions refine generated text and do not apply to static sections.

Podcast¶

Podcast templates define speakers for the whole template and content for each spoken section. Open the settings button to manage hosts in the properties panel.

Field or control Purpose
Host Name, Host Voice Define the available speakers at template level in the properties panel
Section Title Identify the section in the builder
Host Assign one or more available speakers to the section
Data Instructions Specify what the hosts should discuss
Voice Instructions Enable to reveal delivery instructions; disable to hide the text area

For example, data instructions can ask the hosts to summarize delivery risks, while voice instructions request a measured pace and clear pauses between topics.

Editing and dependencies¶

Text, email, PDF, and podcast templates start with one section; PowerPoint templates start empty until slides are added. PowerPoint slides and PDF, email, and text sections can be reordered in the builder. Podcast sections currently cannot be reordered.

Deleting a template clears references from local communications. Repair or reassign those communications before release. For changes through tooling, prefer appending or upserting sections when preserving existing content; replacing the entire parts array rewrites the structure.
