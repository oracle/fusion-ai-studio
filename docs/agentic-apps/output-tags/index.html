Output Tags & Commands Reference¶

Agents send structured content to the app by embedding XML tags that wrap JSON in their LLM response. The framework extracts these tags and renders them. Any text outside the tags is shown as the conversational answer.

Tag Direction Purpose Enabled by (App Experience section)
<oraInfoDisplay> Agent → app Render a widget Select the widgets you want to use (at least one)
<oraInsight> Agent → app Add an actionable insight Enable Actions for the widgets
<oraComms> Agent → app Suggest a communication Enable Communications for the widgets
<oraFormSubmit> App → agent Return form, multi-select, or artifact-edit values —
<oraImmediateInsight> Agent → app Execute an explicitly requested immediate command Action capability; see Immediate Actions

<oraInfoDisplay>¶

<oraInfoDisplay key="unique">
{
  "title": "System Alert",
  "patternId": "cardWidget",
  "description": "Infrastructure alert",
  "properties": { "subject": "High CPU Usage", "summary": "CPU above 90% for 15 min.", "variant": "error" }
}
</oraInfoDisplay>
Attribute / field Description
key attribute Stable display identifier, e.g. supplier-risk-chart. Do not assume unique, contextual, or list are reserved management modes.
title Display title
patternId chartWidget, cardWidget, messageListWidget, changeListWidget, multiRecordWidget, recordWidget, sankeyWidget, multiCardWidget, artifactPreviewWidget, comparisonWidget, toggleBarWidget
description Short description
properties Widget-specific schema. See Widgets.

<oraInsight>¶

<oraInsight>
{
  "title": "Approve Credit Limit Increase",
  "shortDescription": "Blue Yonder Retail has paid on time for 24 months; current limit blocks a $90K order.",
  "actionText": "Approve",
  "followUpCommand": "ora.Invoke(\"approveCreditLimit\", \"{\\\"customerId\\\":\\\"CUST-7781\\\",\\\"limit\\\":250000}\")",
  "priority": false
}
</oraInsight>
Field Required Description
title Yes Under 10 words
shortDescription Yes One sentence
actionText Yes Button label
followUpCommand Yes ora.Invoke(...), ora.Agent(...) or ora.App.*
priority No true = show in the Priority panel

<oraComms>¶

<oraComms>
{
  "type": "text",
  "title": "Alert Plant Maintenance Team",
  "shortDescription": "Line 3 press vibration exceeded threshold twice in 24h.",
  "actionText": "Alert Team",
  "content": "Line 3 hydraulic press vibration hit 11.2 mm/s at 02:14 and 09:47 (threshold 9.0). Recommend inspection before next shift.",
  "params": [ { "id": "channel", "title": "Channel", "defaultValue": "plant-3-maintenance" } ],
  "targetAgent": "MAINT_NOTIFY_AGENT"
}
</oraComms>
Field Description
type email or text
title, shortDescription, actionText Panel display and button label
content Real message body. No placeholders, nothing invented.
params[] {id, title, defaultValue}. Leave defaultValue empty if unknown.
targetAgent Exact delivery workflow code; supply it for text and email

<oraFormSubmit>¶

When a user submits an editable recordWidget, the app sends the agent a block like this:

<oraFormSubmit id="credit_limit_form">
{ "customer_name": "Blue Yonder Retail", "new_limit": 250000, "effective_date": "2026-12-01", "reason": "growth", "notes": "" }
</oraFormSubmit>

The id matches the Record widget's properties.id. Handle it in the workflow, usually on the same path as the request that produced the form.

Commands¶

Commands appear in followUpCommand, card link.action, list items[].action and table rows[].action.command.

Command Handler Signature Examples
ora.Invoke App-defined step chain; configured steps forward the payload ora.Invoke("code", payload?) ora.Invoke("refreshAllAgents")
ora.Invoke("viewOrderDetails", "ORDER-12345")
ora.Agent The agent's normal processing path ora.Agent("text") or ora.Agent({json}) ora.Agent("investigate issue")
ora.App.update Host app: refresh the UI ora.App.update() —
ora.App.launch Host app: open another Agentic App with context (becomes $OraAppContext) ora.App.launch("APP_CODE", {json}) ora.App.launch("ORDERDETAILSAPP", {"orderId":"12345"})

Escaping

Prefer an object payload: ora.Invoke("reviewContract", {"contractId":"C-1042"}). When the whole command is a JSON string, escape its quotes. Older string-context examples remain in this draft; do not assume every receiving workflow uses the same serialization.

Additional tags and command forms¶

Tag or command Contract
<oraImmediateInsight> JSON with followUpCommand only; immediate execution for an explicit user request
ora.InvokeAsync({"mode":"Research"}, "task text") Open Autonomous Outcomes and prepare a plan preview; user starts execution
ora.App.setContext(appCtx) Select an app context string from a context-switcher result
ora.SendComm("inlineActionId") Open the corresponding inline communication from a widget action

For inlineActionId linkage, verify the complete inline communication schema in the generated definition in your environment.

<oraInsight> can also include priorityLevel with critical, urgent, or elevated when priority is true. InitDisplay can combine display, action, and communication tags.

<oraFormSubmit> also covers artifact commits (newValue plus metadata) and multi-select tables (value[0].value plus metadata). Parse by form ID and expected schema. See Actions and Widgets.

Strict JSON paths such as InitSampleQueries and QueryFilterValues are exceptions to the tagged-output pattern: they return their JSON payload directly.
