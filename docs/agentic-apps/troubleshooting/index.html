Troubleshooting¶

Most Agentic App problems come from a mismatch between the AI Agent Studio configuration (what the agent may produce) and the App Builder configuration (what the app asks it to produce), or from context that wasn't passed.

Quick diagnosis¶

Symptom Likely cause Fix
Agent missing from the App Builder / Ask Oracle picker Expose to Agentic Apps is off Turn it on in the team's Details panel
Section card empty at runtime No widgets selected, or no InitDisplay branch Select widgets in the App Experience section; add an InitDisplay handler
Actions panel always empty Enable Actions for the widgets off, or no InitActions branch, or Include in Actions unticked Fix all three
Clicking an action does nothing useful Step chain or receiving handler doesn't match the forwarded input Inspect the action steps; for agent commands, handle InvokeAction and read $inputMessage plus any supplied $OraAction
Agent ignores what the user typed Query handler doesn't pass $context.$system.$inputMessage Wire it into the prompt
Follow-up questions fail $chatHistory not passed Wire in $context.$system.$chatHistory
Wrong agent answers questions Vague team descriptions Rewrite the description and re-test the same question
Widget appears in text but doesn't render Widget type not selected for the node, or malformed JSON Select the widget and validate the JSON schema
Chart looks wrong data length ≠ labels length Match the array lengths
Table misaligned cells count ≠ cols count Match the counts
Change list shows NaN / errors % or $ in numeric values Use plain numbers and set displayType
Communication suggestions never appear Enable Communications off, or Include in Communications unticked, or no applicable agents Fix the configuration
Template dropdown is empty No templates exist Create one in the Template Editor first
Text message never sends No Target Agent / targetAgent Set the exact agent code
Display stale after an action No Refresh Agents step Add it to the action
Context switch has no effect Reload App off and no refresh Turn on Reload App or add Refresh Agents
Attachments ignored MultiFileProcessor tool missing Add the tool to the agent team
Requests time out Too many LLM/agent nodes on a path, or a supervisor team Tighten prompts, cut nodes, move to a workflow; stay under 60 s
Responses arrive as one block Terminal node is Code/Output End terminal paths on Agent/LLM nodes
Subtitle is static No Dynamic Title and Subtitle Agent, or no InitSubtitle branch Set it in App Settings and handle the hint
Users can't see the app Not published, or user lacks the configured Security Roles Publish and check the roles
Edits not visible to users App not re-published Click Publish again

Debugging workflow¶

  1. Reproduce in Preview with the Builder in one tab and AI Agent Studio in another.
  2. Isolate the hint. Work out which message hint the failing behavior depends on.
  3. Inspect the workflow run. Use AI Agent Studio's monitoring and tracing to check that the Switch branch was taken and which variables arrived.
  4. Check the output tags. Make sure the LLM output has well-formed <oraInfoDisplay> / <oraInsight> / <oraComms> blocks with valid JSON.
  5. Check both surfaces. Compare the App Experience section (capability) with the Agent Editor (participation).
  6. Fix one thing at a time and preview again.

Additional builder diagnostics¶

See Testing with ATLAS for the testing workflow.

Symptom Check
Two panels show the same startup graphics Set each panel's instructions and widget override; branch on $OraAppDisplayDiscriminator
App publish blocked while testing a draft Publish the backing workflow; end users need a published version
Dynamic starters show an invalid result Handle InitSampleQueries separately and return only the category JSON
Value picker is empty Check filter workflow, $OraQueryFilter, empty-search handling, and JSON array output
Context switcher repeatedly reloads Return a default only when $OraRequestDefaultAppContext is true
New capability absent Check app/Additional Agent references, selected workflow version, saved metadata, and refresh discovery
Capability discovered but fails to execute Implement reachable InvokeCapability or direct capability-trigger logic
Artifact edits ignored Read oraFormSubmit from $inputMessage; handle newValue and metadata
Test passed but review remains Inspect pending judgment and passed with caveats evidence
