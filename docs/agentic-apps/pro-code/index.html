Pro-Code Development with AI Studio Skill¶

AI Studio Skill is the pro-code path for building Fusion Agentic Applications. It gives AI coding assistants the Fusion-specific knowledge, development patterns and commands they need to generate, validate, test and deploy Agentic App artifacts from a developer's usual tools.

Agentic Application Builder AI Studio Skill
Audience Business users, functional consultants, solution architects Developers and partners
Entry point Natural language + visual builder in AI Agent Studio Natural language to a coding agent in an IDE or CLI
Tools Browser VS Code, a terminal/CLI, Git, AI coding assistants (e.g. Claude Code, OpenAI Codex)
Lifecycle Auto-save, Preview, Publish Git-based source control, local validation, debugging, CI/CD
Availability Release 26B Release 26C
Runtime Fusion-native Fusion-native (same framework)

Both paths produce the same kind of Fusion runtime artifacts and run on the same framework.

What you can build¶

AI Studio Skill can build a complete Agentic App, not just a single agent. That includes specialist agent teams, workflows, tools, business object access, connectors, policies and policy nodes, approvals, enterprise context, communications, and the user experience.

Development workflow¶

flowchart LR
    A[Describe the business<br/>outcome in natural language] --> B[Load AI Studio Skill<br/>into your coding agent]
    B --> C[Generate agents, workflows,<br/>app config & templates]
    C --> D[Validate & test locally<br/><small>replay, synthetic data,<br/>node inspection</small>]
    D --> E[Commit to Git<br/>review & CI/CD]
    E --> F[Deploy into Fusion<br/>as runtime artifacts]
    F -->|iterate| C
  1. Describe the outcome. For example: "An app that helps collectors prioritize overdue accounts by risk and value and drafts outreach."
  2. Give the coding agent the skill and resources. Install AI Studio Skill and point your assistant at it.
  3. Generate. The assistant generates the Fusion artifacts: agent teams, workflows, app configuration, actions and templates.
  4. Test and backtest. Generate tests as you build, validate complete workflows, and use replay, synthesized data and node-level inspection.
  5. Deploy into Fusion. The artifacts deploy directly into Fusion Applications. There is no separate hosting.

Built-in engineering capabilities¶

Capability Description
Testing and simulation Tests generated during the build, full-workflow validation, replay, synthesized data, node-level inspection
Model optimization Compare available models on quality, cost and performance, and use lower-cost models where results are good enough
Deterministic execution Turn business rules, SOPs and approval requirements into consistent, testable workflows and policy nodes
Governance and accountability Guardrails, human oversight where needed, and tracing of model calls, tool use, data access and business actions

Resources Oracle provides¶

  • A public GitHub repository with templates, starter projects, sample applications, reusable assets and reference architectures
  • A README.md and a Release 26C setup and how-to guide
  • Instructions for incremental updates to existing apps

Why deploy into Fusion¶

Apps built with AI Studio Skill are Fusion-native runtime artifacts, not separate AI applications that you host, secure and integrate yourself. They use Fusion data, business objects, workflows, approvals, transaction services, identity, role-based security, observability and auditability directly.
