Oracle AI Agent Studio Documentation¶

Oracle AI Agent Studio for Fusion Applications is the platform for building, testing, deploying and governing AI agents and Agentic Apps that run natively inside Oracle Fusion Cloud Applications (ERP, HCM, SCM and CX).

This site is the technical reference for builders: functional consultants, solution architects and developers who configure agents, compose them into applications, and operate them in production.
